**I want** a modular architecture  
**So that** different ERP components can be developed independently  

**Acceptance Criteria:**

**I want** a database abstraction layer  
**So that** I can interact with the database using ORM  

**Acceptance Criteria:**
- [ ] Configure SQLAlchemy or similar ORM
- [ ] Create base model class
- [ ] Set up database migrations
